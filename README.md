# LoL パッチウォッチ

日本語のRiot公式パッチノートから、サモナーズリフトのチャンピオン調整欄を抽出する個人用Webアプリです。

## 起動

1. Python 3.12以降を用意し、フォルダ内で `pip install -r requirements.txt` を実行。
2. `python scrape.py` を実行。公式ページから情報を取得し `champions.json` と `patches.json` を生成します。
3. `python -m http.server 8000` を実行。
4. ブラウザで `http://localhost:8000` を開きます。

## GitHub Pagesで公開・自動更新

リポジトリのルートに全ファイル（`.github` フォルダを含む）をアップロードし、Actionsの **Update LoL patch notes** を手動実行してデータを生成します。その後 Settings → Pages → Deploy from a branch → main / root を設定します。以後、GitHub Actionsが火曜・木曜に自動更新を試みます。ワークフローに書き込み権限が必要です。

## 注意

- RiotのHTML構造が変わると抽出が失敗することがあります。特にチャンピオンの見出しと「チャンピオン」セクションの階層は要確認です。
- サモナーズリフトのチャンピオン欄のみが対象です。アイテム・ルーン・別モード・パッチ途中の追記・見出し外の変更は対象外の場合があります。
- ページの取得・再配布に関するRiotの利用条件を確認してください。取得頻度は低く設定しています。
- 公式サイトへのリンクを併記しており、誤抽出があれば原文で確認できます。

## 履歴の並び順

パッチノートの公開日が新しい順に並び、同日の場合はパッチ番号順です。日付は**適用日ではなく公開日**です。
